**Empirical Study of Bugs in AI Coding Tools (Claude Code, Codex, Gemini CLI)**

**General Findings on AI Coding Tool Failures:**
* **Functionality Issues:** Over 67% of bugs in these tools are related to functionality.
* **Root Causes:** 36.9% of bugs stem from API, integration, or configuration errors.
* **Common Symptoms:** 
    * API errors (18.3%)
    * Terminal problems (14%)
    * Command failures (12.7%)
* **Workflow Vulnerabilities:** Bugs predominantly affect the tool invocation stage (37.2%) and the command execution stage (24.7%).
