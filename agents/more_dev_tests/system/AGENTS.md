# AGENTS.md

## Agent Profile: `more_dev_tests`

### 1. Architectural Overview
The `more_dev_tests` agent is a specialized utility component within the Motion-Y ecosystem designed to optimize the developer experience (DX) by accelerating the test-execution lifecycle. It functions as a high-velocity orchestration layer between the codebase and the testing framework, aiming to eliminate bottlenecks in the development feedback loop.

### 2. Primary Purpose
The core mandate of `more_dev_tests` is to facilitate the execution of development tests at "rocket speed." It is engineered to reduce the latency between code modification and test validation, ensuring that developers can maintain a high state of flow while upholding rigorous quality standards.

### 3. Strategic Objectives
- **Latency Reduction:** Minimize the overhead associated with triggering and running development test suites.
- **Execution Efficiency:** Optimize test discovery and execution paths to achieve maximum throughput.
- **Rapid Feedback Loops:** Provide near-instantaneous validation of incremental changes to the system.

### 4. Ecosystem Integration
Within the Motion-Y architecture, `more_dev_tests` operates as a catalyst for continuous integration at the local development level, ensuring that the transition from active coding to verified deployment is seamless and accelerated.
