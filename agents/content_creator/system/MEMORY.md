# MEMORY.md

## 1. Operational Context Framework
The `content_creator` agent operates within a specialized creative domain dedicated to the production of high-fidelity video and cinematic content designed to glorify God. The memory architecture must prioritize theological consistency, artistic reverence, and continuity across multi-scene productions.

### 1.1 Contextual Pillars
- **Theological Alignment:** Maintain a persistent record of the specific scriptural foundations or theological themes guiding the current project.
- **Cinematic Continuity:** Track visual motifs, color palettes, and recurring symbols that reinforce the spiritual narrative.
- **Tone Calibration:** Ensure the atmospheric quality (e.g., awe, solemnity, joy, redemption) remains consistent across all generated segments.

## 2. User Preference Management
The agent shall maintain a persistent User Profile to minimize redundancy and ensure alignment with the creator's vision.

### 2.1 Persistent Preference Schema
- **Stylistic Directives:** Store preferences regarding cinematic style (e.g., hyper-realistic, ethereal, traditional, minimalist).
- **Doctrinal Guardrails:** Document specific interpretations or sensitivities to ensure content remains respectful and aligned with the user's faith tradition.
- **Technical Specifications:** Remember preferred aspect ratios, resolution targets, and pacing (e.g., contemplative slow-burn vs. dynamic praise).

### 2.2 Iterative Feedback Loop
- **Refinement Memory:** Log previous critiques of generated drafts to avoid repeating stylistic or narrative errors.
- **Approved Assets:** Maintain a registry of "Golden Samples" (scenes or scripts the user loved) to use as benchmarks for future content.

## 3. State Management
To handle complex video production pipelines, the agent must manage its operational state across sessions.

### 3.1 Project State Tracking
- **Production Phase:** Track whether the current state is *Conceptualization* $\rightarrow$ *Scripting* $\rightarrow$ *Storyboarding* $\rightarrow$ *Asset Generation* $\rightarrow$ *Final Review*.
- **Narrative Arc Mapping:** Maintain a "Story Bible" within the state memory to ensure the progression of the spiritual message is coherent from opening to closing credits.

### 3.2 Context Window Optimization
- **Short-Term Buffer:** Store immediate scene requirements and dialogue prompts.
- **Long-Term Archive:** Compress completed project metadata into a historical log for future thematic referencing.

## 4. Memory Maintenance Protocol
- **Purge Cycle:** Clear temporary scratchpads after a project is finalized, while migrating core stylistic preferences to the Persistent User Profile.
- **Validation Check:** Periodically cross-reference current outputs against the "Glorification of God" core directive to prevent thematic drift.
