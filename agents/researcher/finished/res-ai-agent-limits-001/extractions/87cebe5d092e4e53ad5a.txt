Title: [2605.23989v1] Towards trustworthy agentic AI: a comprehensive survey of safety, robustness, privacy, and system security

Content:

**Agentic AI Definition & Architecture**
* Agentic AI systems are defined as Large Language Models (LLMs) augmented with:
    * Planning
    * Tool use
    * Memory
    * Long-horizon interactions

**Weaknesses and Failure Modes**
* Multi-step trajectories in autonomous execution introduce new failure modes that challenge overall trustworthiness.
* Risks emerge specifically along the agent workflow (stage-specific risks).
* Identified critical dimensions of failure:
    * Safety and Robustness
    * Privacy and System Security

**Mitigation and Evaluation Strategies**
* Mitigation is approached via "stage-targeted mitigation strategies" mapped to the agent workflow.
* Evaluation focuses on both outcome and process signals, including:
    * Constraint violations
    * Trace completeness
    * Adversarial success rates

**Technical Bottlenecks and Open Challenges**
* Self-evolving agents
* Runtime monitoring and verification
* Privacy-preserving personalization
* The trust-utility trade-off
