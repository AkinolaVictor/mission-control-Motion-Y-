Rlinkedin Package (CRAN):
- Purpose: Provides R functions to access the LinkedIn API.
- Capabilities: 
    - Retrieve information about connections.
    - Search for people and jobs.
    - Share updates with network.
    - Create group discussions.
- Technical Dependencies: R (≥ 2.12.0), httr, XML, httpuv.
- Version/Date: 0.2 (Published 2016-10-30).
- Source Code: https://github.com/mpiccirilli/Rlinkedin
