- Tool: rlinkedinads (R package, version 0.2.0, published 2024-01-29).

- Capabilities: 
    - Load ad account hierarchy: accounts, users, campaign groups, campaigns, and creatives.
    - Load ad analytics data from LinkedIn Ad accounts.

- Technical Dependencies: Uses `httr2` (≥ 1.0.0) for HTTP requests.
