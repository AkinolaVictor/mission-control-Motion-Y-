Content:

- Reinforcement learning: software agents take actions in an environment to maximize cumulative reward; studied in game theory, control theory, operations research, information theory, simulation-based optimisation, multi-agent systems, swarm intelligence, statistics, and genetic algorithms.
- In reinforcement learning, the environment is typically represented as a Markov decision process (MDP).
- Many reinforcement learning algorithms use dynamic programming techniques.
- Reinforcement learning algorithms do not assume knowledge of an exact mathematical model of the MDP and are used when exact models are infeasible.
- Reinforcement learning applications mentioned: autonomous vehicles and learning to play a game against a human opponent.
- Self-learning (1982): crossbar adaptive array (CAA) learns without external reward by using emotion as internal reward/state evaluation; computes decisions about actions and emotions about consequence situations in a crossbar fashion; driven by interaction between cognition and emotion.
- CAA routine: in situation s act a; receive consequence situation s'; compute emotion v(s'); update memory w'(a,s) = w(a,s) + v(s').
- CAA has one input (situation) and one output (action/behaviour); no separate reinforcement or advice input; backpropagated value is emotion toward the consequence situation.
- CAA operates in a behavioural environment and a genetic environment; receives a genome/species vector once from the genetic environment, then learns goal-seeking behaviour in an environment with desirable and undesirable situations.
- Feature learning discovers better input representations; classic examples include principal component analysis and cluster analysis; can be supervised or unsupervised.
- Sparse dictionary learning represents a training example as a linear combination of basis functions and assumes a sparse matrix; the method is strongly NP-hard and difficult to solve approximately; k-SVD is a popular heuristic; applied in classification and image denoising.
- Anomaly detection identifies rare items, events, or observations differing significantly from the majority; categories are unsupervised, supervised, and semi-supervised.
- Association rule learning discovers relationships between variables in large databases using strong rules; example: {onions, potatoes} => {burger}; applications include Web usage mining, intrusion detection, continuous production, and bioinformatics.
- Learning classifier systems combine a discovery component, typically a genetic algorithm, with a learning component (supervised, reinforcement, or unsupervised) to identify context-dependent rules applied piecewise.
- Inductive logic programming uses logic programming to derive a hypothesized logic program from examples and background knowledge; useful in bioinformatics and natural language processing; Shapiro's Model Inference System (1981) was a Prolog implementation.

- Genetic algorithms (GA): described as a search algorithm and heuristic technique that mimics natural selection, using mutation and crossover to generate new genotypes in order to find good solutions to a given problem. In machine learning, GAs were used in the 1980s and 1990s; machine learning techniques have also been used to improve the performance of genetic and evolutionary algorithms.
- Gaussian processes: described as popular surrogate models in Bayesian optimisation used for hyperparameter optimisation.
