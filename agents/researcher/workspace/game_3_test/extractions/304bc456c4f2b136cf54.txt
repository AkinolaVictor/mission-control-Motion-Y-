Title: [1209.4560v1] Distributing an Exact Algorithm for Maximum Clique: maximising the costup

Content:

- Paper: "Distributing an Exact Algorithm for Maximum Clique: maximising the costup" by Ciaran McCreesh and Patrick Prosser; arXiv:1209.4560v1, submitted 20 Sep 2012; published in Algorithms 2012, 5(4), 545-587.
- Focus: modifying an existing implementation of an exact maximum clique algorithm so it can be distributed over an ad-hoc cluster of machines.
- Stated goal: achieve significant speedup with minimal development effort, described as "maximum costup."
- Method described: a simple modification to a state-of-the-art exact algorithm for maximum clique that allows distribution across many machines.
- Empirical result: over large hard benchmarks, speedups of an order of magnitude are routine for 25 or more machines.
- Subjects listed: Data Structures and Algorithms; Distributed, Parallel, and Cluster Computing; Discrete Mathematics; Performance.
