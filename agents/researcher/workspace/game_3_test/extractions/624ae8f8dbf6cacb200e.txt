Title: [1706.06697v1] Index Search Algorithms for Databases and Modern CPUs

Content:

- Paper: "Index Search Algorithms for Databases and Modern CPUs" by Florian Gross; arXiv:1706.06697v1; submitted 20 Jun 2017; 70-page Master Thesis with survey on hardware-optimized index search algorithms.
- Subjects: Databases (cs.DB); Data Structures and Algorithms (cs.DS).
- Motivation: CPU speeds increased much faster than memory speeds, creating a Von Neumann CPU-memory bottleneck and long memory-access latencies.
- Modern-CPU optimization targets include data cache, instruction cache, translation lookaside buffers (TLBs), avoiding branch-misprediction penalties, and utilizing SIMD vectorization.
- Index-structure layout has been heavily optimized for data cache, while instruction cache has been neglected.
- NitroGen framework uses code generation to speed up index traversal in main-memory database systems by bringing together data and code, using the instruction cache.
- NitroGen combines index compilation with binary tree search, cache-sensitive tree search, and architecture-sensitive tree search (Kim et al.).
- Mentioned indexing/search approaches: CSS-trees, CSB+ trees, k-ary binary search, and fast architecture-sensitive tree search; parameters such as CSB+ tree node size are discussed.
