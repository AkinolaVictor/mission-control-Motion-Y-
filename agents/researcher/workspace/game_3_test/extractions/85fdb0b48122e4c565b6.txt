Title: Search algorithm - Wikipedia

Content:

- Search algorithms retrieve information stored in a data structure or calculated in a problem domain's search space (discrete or continuous values).
- Choice of search algorithm often depends on the data structure being searched and may include prior knowledge about the data.
- Search algorithms can be made faster or more efficient by specially constructed database structures such as search trees, hash maps, and database indexes.
- Classification by searching mechanism:
  - Linear search: checks every record for the target key in linear fashion.
  - Binary/half-interval search: repeatedly targets the center of the search structure and divides the search space in half.
  - Comparison search: improves on linear searching by successively eliminating records based on key comparisons; applicable to data structures with a defined order.
  - Digital search: works based on properties of digits in data structures using numerical keys.
  - Hashing: directly maps keys to records based on a hash function.
- Algorithms are often evaluated by computational complexity / maximum theoretical run time; binary search has maximum complexity O(log n).
- For virtual search spaces: used in constraint satisfaction and optimization; includes brute-force/uninformed search and heuristics such as linear relaxation, constraint generation, and constraint propagation.
- Local search algorithms view search-space elements as graph vertices with heuristic-defined edges and scan by moving along edges (e.g., steepest descent, best-first, stochastic search); includes metaheuristics such as simulated annealing, tabu search, A-teams, and genetic programming.
- Global search methods apply when the search space is not limited and all aspects of the given network are available to the entity running the search.
- Tree search algorithms are local graph search algorithms for directed acyclic graphs with a single root; traverse nodes in an order prescribed by the algorithm; examples include depth-first search, breadth-first search, backtracking, branch and bound, and alpha-beta pruning. Many tree-search methods are guaranteed to find the exact optimal solution if given enough time ("completeness").
- Game-tree search addresses multiple-player games and successive decisions under uncertainty; examples include minimax, alpha-beta pruning, and A* and variants.
- Graph algorithms find sub-structures in a given graph; examples include Dijkstra's, Kruskal's, nearest neighbour, and Prim's algorithms.
- String searching algorithms search for patterns within strings; examples include Boyer-Moore, Knuth-Morris-Pratt, and suffix-tree-based algorithms.
- Quantum search methods include Grover's algorithm, theoretically faster than linear or brute-force search without data structures or heuristics.
